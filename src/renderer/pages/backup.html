Backup e Restauro

Criar Backup

Crie uma copia de seguranca da base de dados. Pode guardar no computador ou numa pen USB.

Restaurar Backup

Restaure a base de dados a partir de um ficheiro de backup (.db). Atencao: esta acao substitui todos os dados atuais.

Informacoes

  • O backup cria uma copia completa da base de dados
  • Recomenda-se fazer backup diariamente
  • Guarde copias em locais diferentes (USB, disco externo)
  • Ao restaurar, a aplicacao deve ser reiniciada
  • O backup automatico e executado a cada 24 horas (configuravel)
